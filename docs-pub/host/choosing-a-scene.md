# Choosing a scene

A scene is the look of a circle — the background behind everyone, and optionally
something in the centre. Scenes are built by admins and shared across all hosts;
see [Scene library](../admin/scene-library.md) for what one is made of.

You choose one per room. You cannot edit the scene itself unless you are also an
admin.

## Picking one

In the room editor, the **Personalise** panel has a **Scene** tab showing the
library as thumbnails. Click one to select it; the preview above updates
immediately so you can see the result before saving.

Selecting a scene clears any room-specific media you had set — see
[Personalising a room](personalising-a-room.md).

## Finding the one you want

Above the thumbnails:

- **Search scenes** — matches on the scene's name.
- **Center** — `Any`, `None`, `Image`, `Video`. Filter by what sits in the middle
  of the circle.
- **Background** — the same four options for the backdrop.
- **Category** — the groups your admins have set up, plus `Uncategorised`.

Filters combine, and a count tells you how many scenes match. **Clear filters**
puts everything back.

The list shows the first ten scenes; **Show more** reveals ten at a time. If your
current scene is not among the ones on screen — because a filter excludes it, or
it is further down the list — the panel tells you so rather than leaving you
looking at no selection at all.

## Starting from a scene instead

If you know the look you want before you have a room, browse **Scenes** in the
sidebar and use the room icon on any scene's tile. That opens a new room already
set to that scene.

Hosts can browse the scene library read-only: you can look and start rooms from
it, but creating and editing scenes is admin-only.
