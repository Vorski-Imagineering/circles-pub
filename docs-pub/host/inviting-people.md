# Inviting people

## The join URL

Participants join with a link carrying a key:

```
https://app.circles.care/<room-name>?key=<key>
```

Get it from **Join URL** in the room menu, which copies it to your clipboard.

The room is permanent, so the link is too — the same one works for every
gathering in that room. Send it once to a recurring group and reuse it.

## What the key does

The key is the room's access control. Anyone with the link can join; anyone
without it cannot. There is no per-person invitation, no waiting room, and no
account required for participants.

That has two practical consequences:

- **Treat the link as private.** Forwarding it forwards entry.
- **Renaming the room breaks it.** The name is part of the URL, so renaming
  invalidates every copy already sent. See
  [Creating a room](creating-a-room.md).

## Joining as yourself

You do not need the keyed link. Signed in, open `/<room-name>` and you arrive as
host. Using the keyed link puts you in as a participant instead — see
[Hosting basics](hosting-basics.md).

## Before you send it

Worth checking, because participants meet these immediately:

- **They need a working camera.** Circles is a cameras-on space and entry is
  blocked without one. Say so when inviting people who may be on a borrowed
  machine, or joining from a meeting room.
- **Phones are not supported.**
- Everyone arrives muted, which is expected — see
  [Sound and camera](../circle/sound-and-camera.md).
