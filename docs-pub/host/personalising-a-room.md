# Personalising a room

A scene is shared by every room that uses it. When one room needs its own look —
a group's own photograph as the backdrop, a particular image in the centre — you
override the scene for that room only, without touching the scene itself.

## Setting room media

Open the room, then **Personalise Images**. You can set:

- **Background** — an image or video filling the space behind the circles.
- **Centre** — an image or video in the middle.

Each can be uploaded, or given as a URL. Videos are YouTube links; a thumbnail
from the video stands in wherever a still is needed.

## How overrides win

Room media takes priority over the scene, layer by layer:

- Set only a background override, and the room uses your background with the
  scene's centre.
- Set only a centre override, and the scene's background stays.
- Set neither and the scene is used unchanged.

The **Personal** tab in the room editor tells you whether a room currently has
overrides.

## Removing them

Clear the room's media to fall back to the scene. Choosing a different scene also
clears room overrides, so the new scene arrives as its designer intended rather
than half-hidden behind old images.

## Which to use

Change the **scene** when the look should be reusable — other hosts will want it
too, and it belongs in the library. Ask an admin.

Use **personalisation** when the media is specific to this one group and would
only clutter the library.
