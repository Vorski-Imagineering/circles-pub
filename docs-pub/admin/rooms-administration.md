# Rooms administration

**Rooms** in the sidebar. Hosts see the rooms they own; admins see every room on
the site.

Creating and configuring a room is the same job for admins as for hosts, and is
covered once in [Creating a room](../host/creating-a-room.md). This page is only
what admins can do that hosts cannot.

## Seeing everything

The room list shows every room with its host. Use it to find rooms nobody is
maintaining, spot duplicates, and see what the site is actually being used for.

## Reassigning a host

The **Host** field on any room can be changed to any host or admin. This is how
you hand a room over when someone leaves, or when a group changes facilitator.

The room keeps its name, so **its join link keeps working** — participants notice
nothing. The new host gets it in their own room list; the old host loses it from
theirs.

Reassign before deleting a departing user, not after, or their rooms are left
without an owner. See [People and access](people-and-access.md).

## Deleting rooms

Deleting frees the name for reuse and breaks every join link already sent for it.

Historical usage is retained, so deleting a room does not distort your reporting
— see [Usage and reports](usage-and-reports.md).

Rooms are permanent places rather than scheduled meetings, so an idle room costs
nothing. Delete for tidiness, not for hygiene.

## Entering someone else's room

Opening a room as an admin puts you in the circle, visibly, like anyone else.
There is no way to look in unobserved.
