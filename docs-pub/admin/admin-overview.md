# Admin overview

Admins configure the whole site: who can use it, what it looks like, and what
scenes hosts can choose from. Everything a host can do, an admin can do too —
[the host docs](../host) are not repeated here.

## Getting in

Sign in at `/admin`. Access is invite-only; there is no public sign-up unless an
admin has turned it on.

## The sidebar

| Item | Who sees it | What it is |
|---|---|---|
| **Rooms** | Hosts and admins | Rooms. Hosts see their own; admins see all. |
| **Profile** | Hosts and admins | Your name, photo, host logo. See [Your host profile](../host/your-host-profile.md). |
| **Scenes** | Hosts and admins | The scene library. Hosts read-only; admins can edit. |
| **Users** | Admins | People and invitations. |
| **Usage** | Admins | Reporting. |
| **Settings** | Admins | Site-wide configuration. |

Hosts also get a **Stats** entry showing only their own rooms.

## What admins cannot do

There is no way to see or join a circle unobserved. Entering a room puts you in
it, visibly, like anyone else — Circles has no invisible observer role, and
cameras-on applies to admins too.
